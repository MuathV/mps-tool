# أداة تشخيص الإثراء الوظيفي (MPS)

تطبيق ويب عربي (RTL) لقياس الإمكانات التحفيزية لتصميم الوظيفة وفق نموذج خصائص الوظيفة لهاكمان وأولدهام.

## التشغيل

```bash
npm install
npm run dev      # خادم التطوير على http://localhost:5173
npm test         # اختبارات الحسابات والبند العكسي
npm run build    # نسخة إنتاجية ثابتة في مجلد dist
```

مجلد `dist` بعد البناء موقع ثابت يمكن رفعه على أي استضافة (Netlify، GitHub Pages، خادم داخلي).

## البنية

- `src/lib/model.ts` — البنود والمقياس والأبعاد
- `src/lib/scoring.ts` — الحسابات (عكس البند 7، الأبعاد، MPS) ودوال التنسيق المشتركة
- `src/lib/analysis.ts` — التفسير والتوصيات وترتيب الأولويات والملخص
- `src/lib/pdf.ts` — توليد ملف PDF بمقاس A4
- `src/components/Report.tsx` — صفحات التقرير الأربع

## ملاحظة عن ملف PDF

تُرسم كل صفحة بالمتصفح بخط IBM Plex Sans Arabic المضمَّن ثم تُحفظ صورةً عالية الدقة (3×) داخل ملف PDF حقيقي.
يضمن ذلك تشكيل الحروف العربية واتجاه RTL بدقة تامة، لكن النص داخل الملف غير قابل للتحديد أو النسخ.
